# model-schema

The model format of [model-algebra](https://github.com/model-algebra/model-algebra):

| File | Contents |
|---|---|
| `model-schema.json` | JSON Schema (draft-07) of a model |
| `canonical-types.json` | The canonical types: their class, parameters and size |
| `type-descriptor.json` | JSON Schema of the entries of `canonical-types.json` |

The other projects include this repository as a Git submodule and validate models against `model-schema.json`.

## A model

```json
{
  "metadata": { "name": "Event", "version": "1.0.0", "schema": "events", "description": "Things to attend" },
  "fields": [
    { "name": "id", "type": "INT64", "constraints": { "primaryKey": true, "identity": "always" } },
    { "name": "title", "type": "STRING", "parameters": { "length": 200 }, "constraints": { "nullable": false } },
    { "name": "status", "type": "ENUM", "parameters": { "values": ["DRAFT", "PUBLISHED"] },
      "targets": { "postgresql": { "enumType": "event_status" } } },
    { "name": "startsAt", "type": "TIMESTAMP_TZ", "constraints": { "default": { "function": "now" } } },
    { "name": "endsAt", "type": "TIMESTAMP_TZ" }
  ],
  "constraints": [
    { "name": "event_dates", "type": "check", "rule": { "field": "endsAt", "op": ">=", "otherField": "startsAt" } }
  ],
  "indexes": [
    { "name": "event_starts", "fields": ["startsAt"] }
  ]
}
```

### metadata

| Property | Required | |
|---|---|---|
| `name` | yes | Name of the model, unique among related models |
| `version` | yes | Semantic version, e.g. `1.0.0` |
| `schema` | | Database schema (namespace) the model belongs to |
| `description` | | |

### fields

Each field has a `name` and a `type`, and optionally `description`, `parameters`, `constraints` and `targets`.

## Types

The canonical types (`canonical-types.json`):

| Class | Type | Parameters |
|---|---|---|
| numeric | `INT16`, `INT32`, `INT64`, `FLOAT32`, `FLOAT64` | |
| | `DECIMAL` | `precision` (≥ 1), `scale` (≥ 0), both required |
| | `BOOLEAN` | |
| string | `STRING` | `length` (≥ 1, optional) |
| | `TEXT`, `UUID` | |
| binary | `BYTES` | |
| date | `DATE` | |
| | `TIME`, `DATETIME`, `TIMESTAMP`, `TIMESTAMP_TZ`, `DURATION` | `precision`: fractional seconds, 0–6 (optional) |
| compound | `OBJECT` | `ref`: name of the model of the value |
| | `ENUM` | `values`: the allowed strings |
| | `UNION` | `oneOf`: type descriptors, e.g. `[{ "type": "STRING" }, { "type": "INT32" }]` |
| | `JSON` | |
| container | `ARRAY` | `items`: type descriptor of the elements, e.g. `{ "type": "STRING", "parameters": { "length": 20 } }` |

The lowercase types `string`, `integer`, `boolean`, `number`, `array`, `object` and `date` are accepted for older
models.

## Field constraints

| Constraint | Value | Meaning |
|---|---|---|
| `nullable` | boolean | `false`: a value is required |
| `required` | boolean | A value is required (by applications; not a database constraint) |
| `primaryKey` | boolean | The field identifies records |
| `unique` | boolean | No two records have the same value |
| `min`, `max` | number | Range of numeric values |
| `enum` | array of strings | The allowed values |
| `regex` | string | Pattern of text values |
| `identity` | `always` or `byDefault` | Value generated by the database; integer types only |
| `default` | `{ "value": … }` or `{ "function": "now" \| "currentDate" \| "uuid" }` | Value of new records |
| `foreignKey` | `{ "ref", "field", "onDelete"?, "onUpdate"? }` | Reference to `field` of model `ref` |

Referential actions are `cascade`, `setNull`, `setDefault`, `restrict` and `noAction`. `foreign_key` is accepted as
an older spelling of `foreignKey`.

## Table constraints

Constraints spanning one or more fields, in `constraints`, each with a `name`:

| `type` | Also needs | |
|---|---|---|
| `primaryKey` | `fields` | Composite primary key |
| `unique` | `fields` | Values unique in combination |
| `check` | `rule` | A comparison every record satisfies |

A **rule** compares a field with a value or with another field:

```json
{ "field": "endsAt", "op": ">=", "otherField": "startsAt" }
{ "field": "price", "op": "!=", "value": 0 }
```

`op` is one of `=`, `!=`, `<`, `<=`, `>`, `>=`; `value` is a string, number or boolean.

## Indexes

```json
{ "name": "event_open", "fields": ["startsAt"], "unique": false, "where": { "field": "status", "op": "=", "value": "PUBLISHED" } }
```

`fields` are indexed in order; `where`, a rule, makes the index partial.

## Target options

`targets` holds options only one target understands, keyed by target name; other targets ignore them. For
`postgresql`:

| Option | On | |
|---|---|---|
| `type` | fields | Column type override, e.g. `CITEXT` or `INET[]` |
| `enumType` | `ENUM` fields | Name of a native enum type |
| `method` | indexes | `btree`, `hash`, `gist`, `spgist`, `gin` or `brin` |

## Validation

CI checks that the files agree: the schemas compile, every canonical type matches `type-descriptor.json` and is
allowed as a field type by `model-schema.json`, and the type classes match:

```sh
npm install --no-save ajv@8
node .github/scripts/validate-schemas.mjs
```
